# Plano: HidroFlorestas-FrontEnd (projeto mínimo)

## Objetivo
Deixar o projeto no estado mínimo e limpo para você conectar ao GitHub, criar o repositório **HidroFlorestas-FrontEnd**, fazer suas alterações lá e depois eu continuar o trabalho.

## O que será feito

1. **README.md** — reescrever com o nome do projeto "HidroFlorestas-FrontEnd", descrição curta e instruções básicas de desenvolvimento.
2. **Página inicial (`src/routes/index.tsx`)** — substituir o placeholder por uma tela mínima com o nome "HidroFlorestas-FrontEnd" e uma mensagem de "em construção", usando os tokens de tema existentes.
3. **Metadados** — atualizar título e descrição em `src/routes/__root.tsx` e adicionar `head()` próprio na rota inicial (sem "Lovable App").

## O que você fará depois (fora do código)
1. No editor Lovable: menu **+ → GitHub → Connect project**.
2. Autorizar o app Lovable no GitHub e criar o repositório com o nome **HidroFlorestas-FrontEnd**.
3. Fazer suas alterações no GitHub — elas sincronizam automaticamente de volta para cá.
4. Me avisar para eu continuar o trabalho.

## Detalhes técnicos
- Nenhuma dependência nova, nenhum backend, nenhum conector de API do GitHub (a sincronização é o Git sync nativo do Lovable).
- Apenas 3 arquivos alterados: `README.md`, `src/routes/index.tsx`, `src/routes/__root.tsx`.
